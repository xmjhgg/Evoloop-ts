# identity：Java 账号与访问边界

位于 `apps/cloud/.../modules/identity`，拥有 UserAccount、PasswordIdentity、迁移需要的 WeChatIdentity、UserSession、账号状态与必要用途访问资格。提供用户名密码注册、登录、会话读取/撤销，按迁移清单适配微信登录。

注册只建账号及身份，不创建目标/条件/计划/事实。客户端当前账户与用途快照是访问上下文，不把密码/会话/供应商秘密复制为本地业务行。客户端按账户隔离库/队列/附件，云端根据会话确定请求归属。

首期不扩展找回密码、邮箱短信验证、身份绑定或完整数据请求/隐私编排。停用、会话撤销与同步存储访问保护是必要设施，不等于全副本注销。旧用户名相同不自动合并不同账户。
