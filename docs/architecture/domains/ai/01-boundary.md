# ai：Java 模型代理与客户端接纳

Java ai 仅负责凭据、供应商适配、技术任务/租约/重试、输入摘要、结构化结果与用量。输入由客户端从当前本地数据冻结，不要求先同步，不从云端 sync 容器反查计划或构建业务指标。

planning 拥有生成/审查输入语义与接纳；execution 拥有食物候选与个人摄入；review 拥有日周分析与调整判断。业务来源新鲜度、规则适用性、候选接纳和全部人工确认留在客户端。

Java 校验会话/用途/格式/大小/额度与输出结构，不判断健身合理性、计划能否发布或复盘能否确认。Worker 只执行技术任务，不增加自动业务调整、营养服务或业务定时备份。
