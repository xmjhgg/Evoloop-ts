# 账户切换、同步和恢复

注册/登录在线执行，只建立身份与会话。初次本地建空库或经校验下载本人基线；业务账户映射由云端身份确定，不从用户名猜测。账户切换先停止旧同步/AI 界面订阅并清空展示缓存，再打开新账户隔离库；旧库、未同步队列和附件保留。

同步先核验会话与能力，单账户单未决批次串行上传。版本冲突保全原分支，在临时视图补齐远端连续版本，校验后重放本地意图。有冲突进入人工处理，不能只替换 expectedHeadVersion 重传原内容。ACK 与回流分别核对，不因 ACK 清空全部队列。

恢复和升级先检查空间并建立加密恢复点，解密/验摘要/转换旧结构与命令，验证唯一性/引用/业务不变量，再原子切换。存在未同步内容时先保全，不覆盖现库；错误密码、断写、旧版本不支持、缺照片或数据范围不完整都明确提示。

旧隐私请求、旧账号停用或同步资格变化须按真实范围处理，旧设备不能用旧会话重新上传受限数据；离线设备尚未收到云端状态时不能假称即时全局清理。完整注销/外部副本清理本期暂缓，只记录实际做到的访问保护和维护清理。
