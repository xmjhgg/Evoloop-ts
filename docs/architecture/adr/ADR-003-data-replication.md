# ADR-003：账户版本与数据批次同步

状态：采用 14/15 v1.1 的目标约束，2026-10-16，待实施。

云端保存客户端已经计算的规范数据变化；不接受业务命令执行，不做领域合并。以账户 headVersion 比较换取云端简化，接受不同对象并发也可能冲突的代价。客户端基于新基线重放原操作；语义冲突保留分支并要求人工处理。

批次不可变、回执幂等、载荷/回执/head 原子存储；客户端自身导入与恢复负责业务校验。将来若需要云端可信业务裁决或细粒度合并，另立需求和 ADR，不能将本期结构校验逐步扩成隐藏业务引擎。

详见[同步与恢复](../03-sync-and-recovery.md)。
