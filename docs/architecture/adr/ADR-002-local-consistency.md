# ADR-002：本地事务替代服务端业务栅栏

状态：目标设计，2026-10-16。

旧设计依靠 MySQL identity 用户栅栏与 Spring 事件登记协调跨领域写入。新业务只在客户端，故将一致性边界改为共享 UnitOfWork 与按账户写协调；基准、事实、历史、来源、回执、意图、变化批次在可靠本地提交中完成。

事件只用于派生/刷新，不代替来源最终核验。确认/发布即时比较 refs 与包含逻辑空范围的 scopeTokens。云端事务只保护账号状态、AI 状态、同步容器，不与客户端业务事务共享锁或仓储。

三种存储必须通过同一用例的提交/回滚/崩溃恢复契约，多标签页与断写单独覆盖。未通过前不宣称本地原子性已经完成。详见[事务设计](../02-local-transactions.md)。
