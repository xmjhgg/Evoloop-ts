## 关键业务约束



- 今日默认健身展开、其他目标折叠可切换；左计划/右执行，下方该目标日结论分段；复盘读写同一日结论。

- 计划安排先展示分类大目标，再展示目标下本周/下周每日安排；两周均可手工编辑每日动作名称、组数、每组数量单位和休息，增删动作；按日独立保存，校验重审后确认。

- 确认日/周判断与确认计划分开。未来调整显示原/新/理由/日期，已开始或已有实际的目标不追改。

- 我的只维护个人条件与数据管理；改条件不自动重写生效计划。共享身体/睡眠/饮食事实跨目标只统计一次。

- 学习是可使用的轻量模块，复用通用闭环；营养/风险等健身专属规则只用于健身。
