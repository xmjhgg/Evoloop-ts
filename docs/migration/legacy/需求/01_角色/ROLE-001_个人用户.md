## 1. 用户目标与责任

管理本人分类目标，安排周内每一天，查看今日并反馈真实执行，确认每日/每周判断，再决定是否改变未来计划。在我的维护实际身体、作息、可用时间和模块基础。

健身/学习、增肌/减脂、完成/部分完成、进行/暂停是模块、目标属性或状态，不是独立权限角色。

## 2. 权限

| 对象 | 本人可以做 | 限制 |
| --- | --- | --- |
| 资料与目标 | 创建、查看、修改、暂停/恢复/归档 | 不能读取他人数据；资料变更不自动改计划 |
| 周/日计划 | 手工/AI辅助安排、编辑、处理审查、确认未来版 | 最新审查/依据需匹配，阻断不能绕过，不追改已发生目标 |
| 实际记录 | 保存真实反馈，补记、修正、删除误记 | AI草案不是事实，重复不累计，归属日与原目标保留 |
| 日/周结论 | 查看、补充、纠正判断、确认最新范围 | 确认判断不代表发布计划，源变更需重核 |
| 授权及账户 | 查看、撤回、导出、删除、注销 | 明确范围与处理结果，不能把申请当完成 |

## 4. 协作方

PART-001 AI 依据本次授权和版本给草案、审查、结论或估算，不替人登记经历、确认摄入、确认结论或计划。

PART-002 微信支持登录与用户触发的权限；PART-003 营养数据能力为健身提供可核对依据，不参与业务确认。后台维护责任人待指定，不新增管理端角色。
