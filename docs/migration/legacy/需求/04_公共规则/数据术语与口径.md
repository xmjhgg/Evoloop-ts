## 1. 对象与归属

| 对象 | 含义与关系 | 页面主入口 |
| --- | --- | --- |
| 个人资料版本 | 本人身体测量引用、常规作息、可用时间、模块基础与限制；只提供规划依据 | 我的 |
| 分类大目标 | 稳定目标身份、健身/学习类别、描述/衡量/周期与状态 | 计划安排 |
| 周计划/版本 | 必属一个目标与周，包含周重点、每日项目、依据版本和确认时间；本周/下周是日期视图 | 计划安排 |
| 每日计划项目 | 属于目标/周/日，内容、时间、数量、单位、类型、版本；独立的未开始/已开始边界 | 计划安排／今日读取 |
| 计划训练动作明细 | 每日训练项目下的有序动作列表，包含名称、组数、每组数量与单位、休息秒；归属目标/日期/项目/计划版本，每天独立保存 | 计划安排周/日编辑；今日左列读取 |
| 实际事实/版本 | 真实发生内容、归属日期、任务引用或自主标记、适用目标版本、创建与修正时间 | 今日／复盘纠正 |
| 食物分析草案 | 照片候选、份量/营养估算与未知；未确认不入账 | 今日 |
| 日结论/版本 | 本人归属日的汇总及分目标段落、事实与推测、人工补充、覆盖/截止、确认状态和引用版本；历史保留 | 今日与复盘共享 |
| 目标周复盘/版本 | 一个目标/周的计划、日结论和底层事实汇总与人工判断；跨目标总览分开指标 | 复盘 |
| 调整草案 | 最新已确认结论为源的未来差异，合并归属周工作草案，尚未发布 | 复盘发起／计划安排处理 |
| 授权、AI任务、数据请求 | 目的/范围/版本/真实处理状态，跨阶段校验本人权限 | 我的及相关动作 |

关系：个人条件→规划依据；目标→周计划→每日项目（训练含计划动作列表）→实际；实际+当时目标→日结论；目标+周计划+日结论+事实→周复盘；确认结论→未来调整草案→审查→确认计划。个人条件不包含目标实体。

同一身体测量、睡眠或饮食事实在多个目标/页面被引用时只统计一次。自主记录不事后补造过去目标。今日展开状态和类别筛选只是显示状态：左列读取适用计划，右列读取独立实际，卡片下方引用同日日结论目标分段；不因卡片创建新日结论。数据模型与接口字段留待技术方案。

## 2. 四类确认与状态

| 动作/对象 | 最小状态或效果 |
| --- | --- |
| 保存实际反馈 | 确认训练/睡眠/学习事实；饮食要另外核对实际食用才入账；事实成功即成立，不等待AI |
| 计划草案 | 编辑中→审查中→可确认/需修改/信息不足→明确确认→生效；修改后旧审查失效 |
| 日/周结论 | 待生成→生成中→待确认→用户确认；AI失败可保留事实和人工结论，标明来源；依据变化→需更新 |
| 保存人工补充 | 保存用户内容；不自动确认结论，影响旧判断时需更新 |
| 确认结论 | 确认最新版本、来源、覆盖与截止，不能确认任务已全部执行或发布计划 |
| 保存调整草案 | 产生差异，不生效；确认计划才替换未来可调整范围 |
| 目标 | 进行中/暂停/归档；恢复先待规划，新安排确认后再生效 |

## 3. 日期、覆盖与比较

- 北京时间，周一到周日；当前周/下一周按访问日期确定。记录保存时可选择真实过去归属日，不被今日入口强制改日。
- 睡眠按起床日期。周日夜到周一晨归属下周。常规入睡习惯不是睡眠事实；未发生今晚睡眠不作今日失败。
- 训练完成情况对照执行时生效目标；部分保持实际量，未登记单独。分母只含已到执行/登记时点且应执行项目，未来、休息和暂停范围按规则排除，不通过后改计划美化历史。
- 计划动作量用“组数×每组数量+单位”，每组数量为次/秒/分钟，休息统一秒；动作数和总组数仅为计划摘要，不视为已完成数量、统一健康分或可直接累加的实际。力量/按组动作按BR-FIT-015校验，连续计时活动及休息分别表达。实际以独立状态、时长、感受为主，逐动作组次可选；没填不推定完成。
- 记录覆盖按维度分别显示已登记/应登记，包含已经到登记时点的漏记；无计划只显示数量，不虚构达标率。
- 饮食小计仅未删已确认实际份量，以 kcal/g 汇总并保留未知和范围。漏餐时不称全天实际摄入；目标差额显示方向，超出不截断为零，无目标不计算差额。
- 学习时长、页数、题数分别对照同单位目标，文字成果可单独保留，不转换成掌握率或统一分数。
- 周复盘结合每日日结论状态与底层事实核对，不将AI原因推测再次当统计事实。不要求七天完整，但必须说明截至时间和覆盖。

## 4. 变更传播

| 变更 | 日结论 | 周复盘/调整草案 | 已生效计划 |
| --- | --- | --- | --- |
| 新事实、补记、纠正、删除误记 | 对应归属日更新，旧确认失效 | 引用该事实/日结论的报告需更新；相关候选需重算复审 | 保持，必要变化另走确认 |
| 人工日结论补充或重新确认 | 形成新版本，两页同步 | 引用源需核验；影响判断的旧确认和候选需更新 | 保持 |
| 周结论补充/来源变化 | 不代改每日事实/确认 | 周结论需核对最新版本，派生候选需更新 | 保持 |
| 目标/个人条件变化 | 历史对照仍用当时版本 | 相关未完成草案/审查依据失效 | 保持；风险任务另按限制提示 |
| 草案动作名称/组数/数量/单位/休息变化或增删 | 不生成新事实、不回写历史对照 | 当前草案版本更新，旧审查及处理状态失效，最新完整字段重审 | 保存草案不生效，其他日期/原版本保持 |
| 未来计划确认 | 不追溯更改已执行目标 | 周历史保留调整，后续报告引用相应版本 | 只替换确认的未开始范围 |
| 删除/撤回/注销 | 按范围限制生成与展示 | 旧任务不能恢复已删除/受限内容 | 按请求范围与实际状态处理，不能谎报完成 |
