## 1. 原因与前后差异



| 主题 | 原需求表述 | 本轮有效需求 |

| --- | --- | --- |

| 今日入口 | 健身主要、学习紧凑，同页计划/实际/结论 | 首次进入默认全部类别并优先展开健身，其他目标折叠；无健身默认首个可用目标，可筛选/展开/收起，同一时刻最多展开一个 |

| 今日对照 | 三类信息同页，排列关系不明确 | 展开卡内左今日计划、右今日执行，同项目成对排列；窄屏保留左右且无横向溢出 |

| 今日结论 | 今日内显示日结论 | 对照区下方显示该目标今日复盘结论分段与补充/确认入口，仍引用同一归属日日结论；实际保存后刷新右列和下方结论 |

| 每日训练 | 项目/动作、必要组次或时长 | 周列表有动作组数摘要，单日详情有动作名称、组数、每组数量及次/秒/分钟单位、组间休息，汇总动作数/总组数及时间地点 |

| 编辑保存 | 每日不同内容、修改后重审 | 周/日编辑同一草案，各日动作独立，支持增删及字段修改；保存再进入和确认后完整保留各日明细；修改动作使旧审查及处理状态失效 |

| 字段与训练类型 | 日期单位校验、休息单列 | 力量至少一有效动作，非空名称、正整数组数/次数、正计时量、有效单位、非负休息；非法值定位具体字段并阻止有效保存/确认，修正后重审；休息日不强制力量动作 |

| 执行及历史 | 状态、实际量和历史基准独立 | 计划明细不自动成为实际组次，不增加P0实际逐动作强制登记；只改未来可调整项，其他日期、旧文本、已开始/已有实际基准保持 |
