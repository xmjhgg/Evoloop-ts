- 今日首次默认全部类别并优先展开健身，其他目标折叠；可切换/收起，无健身仍可使用。展开卡左计划/右执行按项目成对，下方读取该目标日结论分段；窄屏保留左右、可纵向阅读。
- 执行事实独立保存，随后更新右列和下方结论；卡片显示状态不改变事实/确认，不复制日结论。今日/复盘继续共享同一归属日对象及目标分段、当日总览。
- 计划安排周列表/日详情含每日动作名、组数、每组数量单位、休息及摘要；周/日编辑同一工作草案，动作增删和字段修改按日期独立保存，重新打开完整读回。
- 力量日至少一有效动作，组数/次数为正整数、计时量为正数、有效单位、非负休息；非法字段阻止有效保存/确认，动作变更使旧审查和处理状态失效。休息日不强制力量动作，类型切换仅影响可调整范围。
- 计划动作不自动成为实际组次；P0实际状态/时长/感受维持原粒度，逐动作组次/负重可选。缺失不推定失败或完成，未来睡眠不评价为今日执行。
- 保存草案/确认判断/确认计划各自独立；只发布未来未开始且无实际范围，未涉及日期、历史文本、已开始/已有实际基准保持。原型动作示例、输入上限和模拟审查不作为生产健康阈值。
