## 1. 业务目标与触发

用户在我的查看授权，导出、删除指定数据或注销账户。

## 2. 前置条件与边界

本人身份已验证；删除/注销需明确范围和影响，目标归档另走状态管理。 所有数据限本人；业务状态、日期与版本按公共规则。四个 tab 是同一闭环的视图，不创建四套重复对象。

## 4. 替代与异常流程

| 分支 | 条件 | 处理与结果 |
| --- | --- | --- |
| ALT-01 | 撤回不删除 | 说明保留内容并停止新相关调用 |
| ALT-02 | 供应商或备份未清理 | 显示待处理而非已全部完成 |
| ALT-03 | 删除记录或旧 AI 返回 | 重算受影响汇总和结论，阻止已删内容回写 |

保存失败/不明时先核实结果再重试，不虚假报成功；AI 可退出等待，失败保留事实、旧计划和草案，旧依据返回不能覆盖新版本。拒绝可选授权保留与之无关的人工能力。

## 5. 输入、输出与状态

输入：用途、对象/日期范围及明确动作。输出：请求快照与处理结果。受影响日周结论需更新；未来已确认计划不自动重写。
