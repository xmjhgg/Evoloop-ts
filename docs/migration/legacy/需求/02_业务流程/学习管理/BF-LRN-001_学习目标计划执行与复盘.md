## 1. 业务目标与触发

建立轻量学习目标，在目标下安排周每日内容，在今日反馈，并通过日周结论调整未来。

## 2. 前置条件与边界

学习是可使用的 V1 轻量模块，复用通用身份、计划、日周结论和审查确认，不借用健身营养字段。 所有数据限本人；业务状态、日期与版本按公共规则。四个 tab 是同一闭环的视图，不创建四套重复对象。

## 3. 主业务流程

| 步骤 | 执行方 | 动作与结果 | 关联用例/规则 |
| --- | --- | --- | --- |
| S01 | 用户 | 在计划安排创建学习目标并在我的维护基础 | UC-COM-007、UC-COM-006、UC-LRN-001 |
| S02 | 用户 | 安排本周下周各日学习，审查确认 | UC-COM-008、UC-COM-009、UC-COM-010、UC-LRN-001 |
| S03 | 用户 | 有健身时先从折叠摘要展开学习；仅学习时默认展开，左计划/右执行，反馈实际量及成果 | UC-COM-011、UC-LRN-002 |
| S04 | 系统/用户 | 在学习对照区下方更新/补充学习分段并确认明确范围，复用同一归属日日结论 | UC-COM-012、UC-COM-013 |
| S05 | 用户 | 在复盘纠正记录并结合日结论确认周判断 | UC-LRN-003、UC-COM-014 |
| S06 | 用户 | 按结论提出未来草案，或管理目标状态 | UC-COM-015、UC-COM-010、UC-COM-016 |

## 4. 替代与异常流程

| 分支 | 条件 | 处理与结果 |
| --- | --- | --- |
| ALT-01 | 学习资料缺失 | 可先手工规划，不强制身体信息 |
| ALT-02 | 只记时长 | 不推测掌握程度或考试分数 |
| ALT-03 | 学习与训练时间重叠 | 提示冲突，人选择后分别确认，不跨目标静默调度 |
| ALT-04 | 切换类别/目标或收起学习卡 | 只改变显示，不重复学习事实和日结论，不改记录归属及确认状态 |

保存失败/不明时先核实结果再重试，不虚假报成功；AI 可退出等待，失败保留事实、旧计划和草案，旧依据返回不能覆盖新版本。拒绝可选授权保留与之无关的人工能力。

## 5. 输入、输出与状态

目标→周每日草案→确认→学习事实→通用日结论→目标周复盘→独立未来调整。学习单位和成果保持自身语义。
