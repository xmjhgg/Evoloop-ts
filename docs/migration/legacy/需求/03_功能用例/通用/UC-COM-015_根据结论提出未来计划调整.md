## 1. 用户目标与边界

从已确认日/周结论选择下一天、当前周剩余日期或下一周提出调整，查看理由与差异后转计划安排处理。

## 2. 触发与前置条件

复盘或今日日结论→调整计划；结论最新且已确认。普通手工规划不依赖复盘，走 UC-COM-009。 所有读写限本人；AI 数据授权只在调用时要求，拒绝后保留适用的人工能力。

## 5. 替代与异常流程

| 分支 | 条件 | 处理与最终状态 |
| --- | --- | --- |
| ALT-01 | 结论缺失或需更新 | 提示先确认最新结论，仍可独立手工安排 |
| ALT-02 | 同一未来项目已有候选 | 保留各理由，选择后只形成一个最终值 |
| ALT-03 | 周日调周一 | 使用下周同一对象，不另建第二份周一安排 |
| ALT-04 | 受影响项目已开始 | 不追溯改目标；保留事实并缩小未来范围 |

保存失败或状态不明时明确未保存／待核实，保留输入并先查询已有结果再重试；重复提交返回同一业务结果。AI 等待允许退出再返回，超时可重试；输入版本变化的旧返回只作过期提示，不能覆盖最新内容。
