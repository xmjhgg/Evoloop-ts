协作以[共同约定](../01_领域协作契约与设计约定.md)为准：protectBaseline 与事实保存共享本地事务；范围 token 检测新增事实/目标/计划；AdjustmentBasisVerifier 和 FitnessEvidenceReader 属 planning.api，分别由 review/execution 实现，无反向编译依赖。各域公开通知只更新投影，最终核验当前来源。

每日发布使用稳定 itemId、不可变 itemRevisionId 和唯一当前指针，Publication 保存明确所选变化及完整周组合。用户/日摄入槽保护既有总量及无目标状态；周日夜开始的周一睡眠按真实开始时间保护。健身 BLOCKED 不阻止保存已发生反馈。

工作版审查渠道 RULES/AI：确定性规则覆盖充分才 READY；AI 失败需显式选择 RULES 重审，禁止内容不可绕过。生产健康方法/数值参数和正式评审待 V1 TBD-001/006，未采用原型示例作生产阈值。
