## 4. 交付自检与实际限制

本域完成职责/术语、聚合类图与状态、HTTP/公开API/请求响应/错误/时序、逐表 MySQL 字段与同用户内部 FK/唯一/索引、范围版本与导出/隐私策略、真实需求追溯。公开方法和事件与共同契约对齐，类图可编辑源在 diagrams。

文档自检只能证明链接/结构/引用存在；尚未建立源码、OpenAPI 和 Flyway DDL，也未运行 MySQL迁移/并发/接口/跨域 AC。选择清单事务量、循环 FK、锁时长、性能、事件库恢复均待真实验证。
