## 1. 职责与边界

个人条件及版本在此维护；身体测量和日级疲劳、精神、不适等身体状态事实由本域唯一保存，其他领域只引用其ID和版本。睡眠实际及某次训练的感受属于execution；个人常规作息仅是规划依据，长期限制与日级状态分别建模。

本域拥有身体证据，planning拥有关联健身限制规则，review引用身体事实形成判断。保存条件/事实不自动改变生效计划，学习不要求健康字段。依据见[整体业务领域设计](../00_整体业务领域设计.md)和[协作契约](../01_领域协作契约与设计约定.md)。

## 3. 协作与交付状态

公开 `ProfileApi.getConditions/getBodyFacts/getSourceTokens` 返回不可变修订和 refs+scopeTokens；COMMON/类别条件范围与每日身体范围检测新增/纠正/删除。只改可用时间复用作息组件ID，不读取或复制健康正文；日状态移日遇目标已有事实明确冲突。

所有短写先 identity 用户处理栅栏，采用公共幂等与单一事件登记，不另建outbox。导出短事务固化确定修订清单；隐私清理包含正文、历史、选择清单及产物，不能借审计绕过删除。允许编译依赖 identity::api/shared，不依赖 planning/execution/review 实现。
