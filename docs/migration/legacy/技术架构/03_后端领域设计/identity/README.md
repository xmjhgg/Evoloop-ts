identity 拥有账户、微信关联、密码身份、会话、按用途授权，以及导出、删除、注销请求与真实阶段回执。账户根行提供全域短事务栅栏；数据所有者自行处理并回执，identity 不反向导入其内部表。

密码登录作为长期能力保留，本次仅由管理员预建账号，不开放注册、找回密码、账号管理或身份绑定页面/API。微信与密码进入同一内部账户/会话模型，用户名不替代 userId。创建脚本建立新账户和密码身份，不伪造微信关联，也不按同名自动合并微信账户。浏览器 Basic Auth 属于部署入口保护，不是业务身份或用途授权。
