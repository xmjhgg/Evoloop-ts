## 4. 验证安排与交付限制

领域测试验证有限覆盖/单位/确认范围/人工版本；应用和模块测试验证来源采集、AI接纳、只读verifier及单一事件协议；真实MySQL8.4验证日周唯一、复合FK/manifest、两个连接下新增事实与确认竞争、全局规则切换与当前basis核验。固定导出、部分隐私删节、旧任务/事件返回分别故障注入。

跨域端到端测试需包含：45分钟计划登记30分钟→两页同一结论→人工原因与独立确认→同周/跨周候选合并→再次审查与明确发布；之后纠正事实使结论来源需更新且未来已发布版本保持。纯学习相同闭环不需要健康资料。真实AI分析质量另按TBD-002评测，不能以模拟返回证明效果。

01～03由独立review_design子智能体设计；服务额度限制后，主设计补齐04表结构与本追溯文档，并联审token代码、组件确认和跨周分组协议。正式OpenAPI/schema、V050 DDL、源码及REV-T/原UC验收未实现或运行；健康规则/供应商/保留政策待正式落实。最终文档检查见[总核对记录](../02_设计核对记录.md)。
