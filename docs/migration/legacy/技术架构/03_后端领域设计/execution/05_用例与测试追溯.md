## 4. 实施与外部决策

领域/application测试先使用合成事实、可控时间和受控端口；MySQL8.4集成测试再应用V001/V010/V030/V040，证明复合FK/唯一槽/同事务回滚/双连接竞争。事件/重启/存储和供应商故障单独注入；模型效果、营养来源、图片限制和成本误差标准待批准后评测。

TBD-001健康计算/限制归planning策略；TBD-002实际模型、营养来源及图片能力由相关所有者共同落实；TBD-003保留/删除/备份证据由identity与各实际持有者明确。本域不编造生产营养源/阈值/期限。OpenAPI、SQL、源码、上述EX-T及真实端到端验收均未完成。

本域01～04由独立execution_design子智能体设计；其服务额度限制后，主设计补齐本追溯文档并收口幂等键/保护链/维护权限一致性。最终静态检查结果由[总核对记录](../02_设计核对记录.md)汇总。
