# 苹果客户端实现与范围更新

用户授权继续苹果客户端代码重构，并明确不需要考虑数据迁移。该要求优先于此前“页面/旧数据切换后续另行授权”的范围描述。

本轮实现 `apps/mobile` Expo 开发构建，复用共享 TS 业务核心；新增 client-model 与 design-tokens 的受控公开入口。页面、Feature、Gateway、平台适配各自分工，实际映射见[页面地图](../../engineering/page-map.md)。

为客户端用途授权补充受控告知正文接口、告知版本和账户用途版本校验；撤回不依赖告知服务，不能覆盖其他设备的新用途设置。Java 仍只有身份、AI、同步与必要基础设施。

旧库、旧备份和旧队列转换、灰度切换不在当前范围；历史阅读材料保留。当前版本自己的备份恢复、同步分支和附件保全继续执行工程约束。小程序、真实 AI 评测、全部原业务字段/指标和 iOS 设备验收没有因此自动完成。
